**Underlying Defect**

Instead, it assumes data will be returned and attempts to manipulate it (e.g., `.sort()` or `.length`), causing a runtime error.

This is a **frontend data handling bug**, not a backend or authentication issue. The authentication failure is a trigger, but the defect lies in the UI’s failure to validate data before processing.
