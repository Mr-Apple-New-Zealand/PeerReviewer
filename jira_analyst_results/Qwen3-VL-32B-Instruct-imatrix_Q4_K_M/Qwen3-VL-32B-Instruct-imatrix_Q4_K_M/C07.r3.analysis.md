**Incident Timeline (BANK-450)**

- **09:31 NZST**: Transfer errors begin to appear in monitoring dashboards.
- **09:47 NZST**: Monitoring alert fires due to TransferErrorRate exceeding 20%.
- **09:52 NZST**: Incident declared by Sam Okafor. Error rate at 64%.
- **10:05 NZST**: Marcus Reid reports 40+ support calls in the last 15 minutes.
- **10:10 NZST**: Priya Nair suggests database issue due to slow queries on transactions table.
- **10:24 NZST**: Sam Okafor identifies root cause: JWT signing key rotated in OPS-81 config deploy; Transactions API still validates with old key. Error code: `IDX10503: Signature validation failed`.
- **10:31 NZST**: Sam Okafor initiates rollback of OPS-81 config deploy.
- **10:44 NZST**: Rollback complete. Transfer error rate drops to under 1%.
- **10:50 NZST**: Incident resolved.

---

**Time to Detect (TTD)**:  
From **09:31** (first errors appear) to **09:47** (alert fires) → **16 minutes**  
*(Note: Alert fired 16 minutes after errors began, but incident was declared at 09:52, which is 25 minutes after first errors. TTD is typically measured from first occurrence to detection, so 16 minutes is correct.)*

**Time to Recover (TTR)**:  
From **09:47** (alert fires) to **10:44** (recovery confirmed) → **57 minutes**  
*(Alternatively, from 09:52 incident declared to 10:44 recovery: 52 minutes. But standard TTR is from detection to recovery, so 57 minutes is accurate.)*

---

**Root Cause**:  
The JWT signing key was rotated in config deploy **OPS-81** without updating the key used by the **Transactions API** for token validation. This caused the Transactions API to reject valid tokens signed with the new key, resulting in `IDX10503: Signature validation failed` errors and failed transfers for all users.

---

**Summary**:  
- **Incident**: All transfers failing due to JWT signature validation errors.  
- **Detection**: 16 minutes after errors began.  
- **Recovery**: 57 minutes after detection.  
- **Root Cause**: Asymmetric key rotation in Auth service without syncing the new key to Transactions API.  
- **Resolution**: Rollback of OPS-81 config deploy.  
- **Post-Incident Review**: Scheduled for 2026-09-16.
