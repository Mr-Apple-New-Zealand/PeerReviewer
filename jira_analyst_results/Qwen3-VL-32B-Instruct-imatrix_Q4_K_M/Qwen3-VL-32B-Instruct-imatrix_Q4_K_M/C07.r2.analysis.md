**Incident Timeline (BANK-450)**

- **09:31 NZST**: Transfer errors begin appearing in monitoring dashboards.
- **09:47 NZST**: Monitoring alert fires due to TransferErrorRate exceeding 20%.
- **09:52 NZST**: Incident declared by Sam Okafor. Error rate at 64%.
- **10:05 NZST**: Marcus Reid reports support queue spiking with 40+ calls in 15 minutes.
- **10:10 NZST**: Priya Nair suggests database issues due to slow queries on transactions table.
- **10:24 NZST**: Sam Okafor identifies root cause: JWT signing key rotated in OPS-81 config deploy; Transactions API still validating against old key, causing 401 errors ("IDX10503: Signature validation failed").
- **10:31 NZST**: Sam Okafor initiates rollback of OPS-81 config deploy.
- **10:44 NZST**: Rollback complete; error rate drops below 1%.
- **10:50 NZST**: Incident resolved.

---

**Time to Detect (TTD)**:  
From first error occurrence (09:31) to incident declaration (09:52) → **21 minutes**

**Time to Recover (TTR)**:  
From incident declaration (09:52) to recovery (10:44) → **52 minutes**

**Total Downtime (from first error to recovery)**:  
From 09:31 to 10:44 → **73 minutes**

---

**Root Cause**:  
The JWT signing key was rotated in the config deploy OPS-81 without updating the key used by the Transactions API for signature validation. This caused the Transactions API to reject valid tokens signed with the new key, resulting in 401 errors for all transfer requests.

---

**Note**:  
The incident was resolved by rolling back the config deploy (OPS-81). A post-incident review is scheduled for 2026-09-16.
