## 1. Summary
MOB-104 is a High-priority bug in mobile 5.4.1: the mobile app shows a blocking "Error!" dialog at login and will not let the customer (or the reporter's test account) get in. The dialog tells the user to log in to Online Banking (web) and complete a questionnaire, but the wording is confusing and there is no in-app way to do that. The reporter reproduced it on a test account, so it is not specific to one customer.

- **No linked issues** to the questionnaire feature or the auth rule that raises this flag, so the triggering backend condition is unknown.

## 5. Suggested next actions
- **Assign an owner** (a developer or tech lead on Mobile/Auth) and put it into a sprint — it is currently unowned and High priority.
- **Product/PM decision:** confirm intended behaviour — is blocking mobile login until the web questionnaire is completed *by design*?

  - If **no (bug):** find the auth rule that sets the "questionnaire required" flag and determine why it is raised for these accounts.
- **Identify the trigger:** confirm which accounts and which backend state produce the dialog (e.g. is it all accounts, or only those with an incomplete questionnaire?), so the test account `TESTRELAXLUX4` can be used to verify the fix.
- **Add acceptance criteria** to the ticket (expected behaviour, exact user-facing message, and whether a deep link is required) before development starts.
