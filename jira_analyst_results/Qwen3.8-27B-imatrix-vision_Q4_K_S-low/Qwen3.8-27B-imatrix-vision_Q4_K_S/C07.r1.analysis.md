## Root Cause

The config deploy **OPS-81** at 09:30 rotated the JWT signing key used by the Auth service. Auth immediately began issuing tokens signed with the **new** key, but the Transactions API continued to validate tokens against the **old** key. Every transfer request carried a token the Transactions API could not verify, producing `401` responses with error code `IDX10503: Signature validation failed`.

The failure mode was a **key-rotation process gap**: the deploy changed one side of a cryptographic pair without synchronising the validation side.
