## Root Cause

The config deploy **OPS-81** (applied at 09:30) rotated the JWT signing key used by the Auth service. Auth immediately began issuing tokens signed with the new key, but the Transactions API continued to validate incoming tokens against the old key. Every transfer request therefore failed with a `401` and the error `IDX10503: Signature validation failed`, affecting all users.

This is a **configuration inconsistency introduced by a change**: the key rotation was applied on one side of an auth pair without the corresponding update on the validating side.
