## Root Cause

The config deploy **OPS-81** (09:30) rotated the JWT signing key used by the Auth service to issue tokens, but the key that the Transactions API uses to **validate** those tokens was not updated in the same deploy. As a result, the Transactions API rejected all newly issued tokens with `IDX10503: Signature validation failed` (HTTP 401), causing a total failure of the transfer function for all users.
