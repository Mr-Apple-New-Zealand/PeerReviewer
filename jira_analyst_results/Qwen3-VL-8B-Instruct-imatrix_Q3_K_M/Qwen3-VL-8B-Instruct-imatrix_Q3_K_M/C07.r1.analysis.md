**Incident Timeline for BANK-450: P1: Transfers failing for all users**

---

**Summary**  
A high-severity incident occurred on 2026-09-11 at 09:31 NZST, where transfer requests began failing across all users due to a misalignment between the Auth service’s JWT signing key and the Transactions API’s validation key. The issue was detected via monitoring (TransferErrorRate > 20%) at 09:47, and fully recovered by 10:42 after rolling back the faulty config deploy (OPS-81). Root cause: JWT key rotation without updating the Transactions API’s validation key.

**Root Cause**  
The JWT signing key was rotated via config deploy **OPS-81** at 09:30, but the **Transactions API was not updated to validate against the new key**. This caused all incoming tokens to fail signature validation, resulting in 401 Unauthorized responses and transfer failures. The issue was resolved by rolling back OPS-81.
