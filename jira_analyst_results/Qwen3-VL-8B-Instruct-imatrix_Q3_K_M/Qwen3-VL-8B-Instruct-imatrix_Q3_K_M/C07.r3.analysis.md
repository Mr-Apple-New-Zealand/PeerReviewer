**Incident Timeline for BANK-450**

**Summary**  
A high-priority incident where all user transfers failed due to a misconfigured JWT key rotation (OPS-81), causing 401 Signature Validation Failures. The issue was detected at 09:47 (error rate >20%) and fully recovered by 10:42 after rollback. Root cause: Auth service rotated signing key without updating the Transactions API’s validation key.

**Root Cause**  
The JWT signing key was rotated via config deploy **OPS-81** at 09:30. However, the **Transactions API continued validating tokens using the old key**, while Auth service started issuing tokens with the new key. This mismatch caused 401 errors for all transfer requests.

---

- **Affected Components**: Transactions API, Auth Service  
- **Error**: `IDX10503: Signature validation failed` (401s)  
- **Root Cause**: Key rotation without API validation key sync
