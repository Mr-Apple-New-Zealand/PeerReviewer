**Key Details:**
- **Repro Steps:** After successful transfer, dashboard shows old balance. API returns correct new balance immediately. Refreshing page doesn’t help.
- **Root Cause:** `BalanceCache` (15-min local storage) is not invalidated after a transfer.
- **Fix:** Invalidate cache on `TransferCompleted` event.
- **Affected Components:** Web (dashboard), Mobile (notifications — MOB-88).
- **Acceptance Criteria:**
  - Balance updates immediately after transfer (without logout).
  - Notification shows correct post-transfer balance.
  - Cache is invalidated on successful transfer.
