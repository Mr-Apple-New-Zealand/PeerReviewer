**Summary:**
The `statements-api` performance degraded drastically after release 4.7.0, with `GetStatementLineQuery` requests taking up to 72 seconds (vs. ~300ms before), causing timeouts and user-facing failures. The `GetAccountSummaryQuery` also became slower but remains within acceptable limits. The regression is not caused by changes in the statements module itself (per Tom Becker), but likely due to a side effect of the `20260914_2100_ReindexStatementLines` migration, which appears to have triggered a thread pool starvation and cascading slowdowns.

- Key blocker: **Thread pool starvation** detected in logs, suggesting infrastructure or concurrency issues post-migration.

**Key Details:**

✅ **Before (4.6.3, 2026-09-13):**
- `GetStatementLineQuery`: 281–319ms (fast and consistent)
- `GetAccountSummaryQuery`: 3102–3341ms (slow but stable)
- No timeouts or warnings — all requests completed within 1000ms threshold.

✅ **After (4.7.0, 2026-09-15):**
- `GetStatementLineQuery`: 35–72 seconds (multiple warnings >10s threshold)
- `GetAccountSummaryQuery`: 3011–3402ms (still slow, but not critical)
- **Thread pool starvation**: 31 queued work items, 0 available threads for 4200ms — indicates system overload.
- **Migration applied**: `20260914_2100_ReindexStatementLines` — likely the root cause.

**What Changed:**
- **Migration `20260914_2100_ReindexStatementLines`** was applied post-release — likely triggered a heavy background job or data reindexing that consumed all available threads.
- **Thread pool exhaustion** — 0 available threads for 4.2s, leading to queued work items and cascading timeouts.
- **No code changes to statements module** — as per Tom Becker — but the migration likely affected underlying data or concurrency model.

---

**What Did Not Change:**
- The `GetAccountSummaryQuery` performance is similar — only the `GetStatementLineQuery` is affected.
- The `statements-api` app version changed from 4.6.3 → 4.7.0, but the core logic for statements queries remains unchanged — the issue is infrastructure or migration-triggered.
