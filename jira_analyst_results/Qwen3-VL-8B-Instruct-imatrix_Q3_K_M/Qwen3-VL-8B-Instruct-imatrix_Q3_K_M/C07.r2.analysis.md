**Root Cause**  
The JWT signing key was rotated in config deploy **OPS-81** at 09:30, but the **Transactions API was not updated to validate against the new key**. This caused all transfer requests to return 401s with error “IDX10503: Signature validation failed”. The issue was resolved by rolling back the deploy.
