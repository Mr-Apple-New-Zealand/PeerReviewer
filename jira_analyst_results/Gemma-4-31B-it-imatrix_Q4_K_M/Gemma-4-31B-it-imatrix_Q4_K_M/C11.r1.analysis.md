**Error Message:** "Error! To keep using mobile app, please log in to Online Banking and fill the customer's questionnaire."

### Summary
Users are unable to log into the mobile app (v5.4.1) because an error dialog appears and blocks access. The message instructs users to log into Online Banking to complete a customer questionnaire.

### Current state
*   **Status:** Open
*   **Owner:** Unassigned
*   **Blocking progress:** Lack of clarity on whether the app is intended to block login entirely or simply provide a warning.

### Key details
*   **Steps to reproduce:** Attempt to log into the mobile app with a user account (confirmed via test account in MOB-104).
*   **Affected versions:** mobile 5.4.1
*   **Components:** Mobile App, Auth
*   **Missing information:** Acceptance criteria (expected behavior).

### Risks and gaps
*   **Ambiguity:** There is a conflict/uncertainty regarding the intended UX; Tom Becker notes that it is unknown if the app should block login or just warn the user.
*   **Dependency:** The issue is linked to the status of a "customer's questionnaire" within the Online Banking system.

### Suggested next actions
*   **Product Owner:** Define whether this error should be a "hard block" preventing login or a "soft warning" that allows the user to proceed.
*   **Development/QA:** Confirm if this behavior was intentionally introduced in version 5.4.1.
