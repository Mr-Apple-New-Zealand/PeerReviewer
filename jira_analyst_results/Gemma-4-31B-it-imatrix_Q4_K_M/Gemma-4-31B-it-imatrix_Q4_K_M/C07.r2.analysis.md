**Root Cause**
The JWT signing key was rotated during config deploy OPS-81. While the Auth service began issuing tokens with the new key, the Transactions API continued to validate tokens against the old key, resulting in 401 "IDX10503: Signature validation failed" errors.

**Time to Detect (TTD)**
16 minutes (From the start of errors at 09:31 to the monitoring alert at 09:47).

**Time to Recover (TTR)**
71 minutes (From the start of errors at 09:31 to the error rate dropping below 1% at 10:42).

**Incident Timeline (BANK-450)**
*   **09:30**: Config deploy OPS-81 occurs, rotating the JWT signing key for the Auth service.
*   **09:31**: Errors begin appearing on dashboards.
*   **09:47**: Monitoring alert fires (TransferErrorRate > 20%).
*   **09:52**: Incident officially declared by Sam Okafor; error rate is 64%.
