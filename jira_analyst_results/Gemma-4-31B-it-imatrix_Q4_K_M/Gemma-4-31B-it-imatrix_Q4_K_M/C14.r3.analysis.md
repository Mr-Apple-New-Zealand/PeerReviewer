### Broken Components (Prioritized)
*   **High Severity: Masterfile-API Integration (Root Cause of OPS-92)**
    *   **Issue:** `AddPaymentRoutingRuleSecondaryCommand` and `BulkUpdateSecondaryBranchesCommand` are failing because the `masterfile-api` is returning a `403 (Forbidden)` response.
    *   **Evidence:** Logs show `Dapr.Client.InvocationException` when calling `branchlocation/get` and `branchlocation/GetAll`.
    *   **Inference:** This is a permissions or authentication failure between the Payments API and the Masterfile API, not a database issue.
*   **Medium Severity: Database Type Mismatch**
    *   **Issue:** `SearchPaymentRoutingRuleQuery` is crashing with `Microsoft.Data.SqlClient.SqlException`: "Conversion failed when converting the ****** value '******' to data type ******".

    *   **Issue:** `GetMonitorJobsQuery` is intermittently failing with "Execution Timeout Expired".
    *   **Evidence:** Repeated `SqlException` (Error Number: -2) between 22:26 and 22:29.
