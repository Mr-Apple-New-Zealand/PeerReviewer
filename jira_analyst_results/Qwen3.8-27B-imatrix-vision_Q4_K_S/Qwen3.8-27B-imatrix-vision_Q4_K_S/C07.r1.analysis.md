## Root Cause

Config deploy **OPS-81** (executed 09:30) rotated the JWT signing key used by the **Auth** service without a corresponding update to the key the **Transactions API** uses for token validation. After the deploy:

- Auth began issuing tokens signed with the **new** key.
- Transactions API continued to validate incoming tokens against the **old** key.
- Every transfer request was rejected with **401 — "IDX10503: Signature validation failed"**, driving the error rate to 64 % and breaking transfers for **all users**.

The fix was a **rollback of the OPS-81 config deploy**, restoring the original signing key.

The ticket links BANK-450 as *caused by* OPS-81, confirming the causal chain.
