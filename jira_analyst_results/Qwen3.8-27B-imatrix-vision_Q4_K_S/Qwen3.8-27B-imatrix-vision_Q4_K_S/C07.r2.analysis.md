## Root Cause

The OPS-81 config deploy (09:30) rotated the JWT signing key used by the **Auth** service. After the deploy:

- Auth began **issuing** tokens signed with the **new** key.
- The **Transactions** API was still configured to **validate** tokens against the **old** key.

Every transfer request therefore failed at the Transactions API with a 401 and error code **IDX10503: Signature validation failed**, producing the 64 % error rate observed.

The fix was a rollback of the OPS-81 deploy, which restored the old key on both sides and returned the error rate to under 1 % within roughly 11 minutes of the rollback starting (10:31 → 10:42).
