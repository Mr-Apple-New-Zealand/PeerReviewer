## Answer: One near-duplicate (BANK-425), one related-but-distinct bug (MOB-88), one causal task (BANK-419)

BANK-425 is a near-duplicate of BANK-440. MOB-88 is a separate bug with a different root cause. BANK-419 is not a duplicate; it is the shipped feature that created the conditions for both web bugs.

---

## 1. Summary

BANK-440 reports that the web dashboard shows a stale balance after a transfer, even though the API returns the correct value immediately. The likely root cause (identified in BANK-425's comment) is the `BalanceCache` local-storage cache introduced in 3.1.4 by BANK-419, which has a 15-minute TTL and is never invalidated on a successful transfer.

---
