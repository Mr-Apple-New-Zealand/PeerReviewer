2. **Escalation is in progress but unverified.** Jo Tan asked the partner manager to escalate on 9/11, but there is no follow-up comment confirming the escalation was actioned or that Northwind has responded.
3. **Sprint buffer is minimal.** Even in the best case, Ravi's 2-day window ends on 9/17–9/18, leaving only a few days for sprint review and release sign-off before 9/24.
4. **Production import not yet scoped.** OPS-77 mentions staging *then* production, but there is no comment describing the production procedure, approval path, or maintenance window. This is a gap if the release timeline forces a compressed rollout.
5. **No linked tickets for the Northwind sandbox environment.** AC2 requires a working sandbox; if the sandbox itself has issues, that adds untracked risk.
