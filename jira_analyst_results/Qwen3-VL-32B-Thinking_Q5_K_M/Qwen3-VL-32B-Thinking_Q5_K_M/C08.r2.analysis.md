# Current State of BANK-360: Migrate transactional email from SMTP to EmailHub API

## Summary
This story involves migrating transactional emails (password resets, statements, transfer receipts) from SMTP to EmailHub API. The project is 99% complete, with all technical components implemented except for the load test. Key decisions changed the approach for statement delivery from attachments to secure download links, and established a fallback to SMTP until 2026-12-31 with feature flag control.
