# Analysis of BANK-495

## Summary
The batch actions screen in the bank UI throws "Cannot read properties of undefined (reading 'sort')" and goes blank when the user's session expires. A series of 401 (unauthorized) API responses triggered this error after the user had the tab open for an extended period, which the application failed to handle gracefully. The user must reload the page to restore functionality.
