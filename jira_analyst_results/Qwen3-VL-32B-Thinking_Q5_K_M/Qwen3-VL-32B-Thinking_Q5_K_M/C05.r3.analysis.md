# Duplicate Analysis of BANK-440

BANK-425 is a duplicate of BANK-440. MOB-88 and BANK-419 are related but not duplicates.

## Duplicate Assessment
- BANK-425: **Duplicate of BANK-440** - Both tickets describe the same web dashboard balance not updating after transfers in version 3.1.4. BANK-425 provides detailed analysis of the caching issue (15-minute local storage cache not invalidated after transfers) that explains the symptom described in BANK-440 (only updating after logging out and back in).
- MOB-88: **Not a duplicate** - Affects mobile push notifications (not web dashboard), shows pre-transfer balance in notifications, and has a different root cause (using TransferRequested event instead of TransferCompleted).
- BANK-419: **Not a duplicate** - A completed task that implemented the caching behavior causing the issue, not a bug report describing the symptom.

## Recommendations for Each Ticket
- **BANK-440 (main ticket)**: Keep open as the primary issue. No action needed since it's already the main ticket. The current description (3.1.4, medium priority) is sufficient.
- **BANK-425**: Close as duplicate of BANK-440. The fix suggestion (clear BalanceCache on transfer success) should be added as a comment to BANK-440. This ticket is 8 days older but has more detailed information.
- **MOB-88**: Continue as separate issue. The root cause (notification event timing) is distinct from the web dashboard caching issue. Keep in In Progress status with Ravi Kumar as assignee.
- **BANK-419**: Add a link to BANK-440 showing this task introduced the caching behavior that caused the issue. This task was completed in 3.1.4 (as confirmed in comments) and is now in "Done" status.

## Key Supporting Details
- Both BANK-440 and BANK-425 affect the same component (Web), version (3.1.4), and describe the same user experience issue with dashboard balance updates.
- BANK-425 provides the root cause explanation: "The web front end caches the balance response in local storage for 15 minutes (BalanceCache). Nothing invalidates the cache after a transfer."
- This explanation directly supports BANK-440's symptom: "It only updates after logging out and back in" (the cache is likely cleared during login).
- MOB-88 specifically references mobile app components (iOS/Android) and a different symptom (push notification showing wrong balance).
- BANK-419's comment confirms: "Done, shipped in 3.1.4" - this is the implementation that created the problem reported in BANK-440.
