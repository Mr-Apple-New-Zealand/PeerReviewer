# BANK-412 Analysis

**Summary**  
Mobile web transfers with a timeout followed by "Retry" cause the source account to be debited twice while the destination account is credited only once. This happens because the server treats the retry as a new transfer (no idempotency key) and the debit/credit operations aren't in a single database transaction. Three customers have been impacted, requiring manual transaction reversal.
