**Incident Timeline: BANK-450 – P1: Transfers failing for all users**

---

### **Summary**
- **Incident**: All transfers failing due to "Signature validation failed" error (IDX10503) in the Transactions API.
- **Root Cause**: JWT signing key was rotated via config deploy OPS-81 without updating the validation key in the Transactions API.
- **Status**: Resolved (Fixed) – **Resolved on 2026-09-11 10:42**.
- **Impact**: All users experiencing transfer failures; 64% error rate at 09:47.
- **Affected Systems**: Auth service, Transactions API.

---

### **Current State**
- **Status**: Resolved  
- **Owner**: Sam Okafor  
- **Resolution**: Fixed (via rollback of OPS-81 config deploy)  
- **Root Cause**: JWT signing key rotation in OPS-81 config deploy did not update the Transactions API’s validation key.  
- **Time to Detect**: **~15 minutes** (from 09:31 when error rate spiked to 64% to 09:47 when alert fired)  
- **Time to Recover**: **~10 minutes** (rollback completed at 10:42, error rate back under 1%)

  - **No communication** between Auth and Transactions API was established at the time of the deploy
