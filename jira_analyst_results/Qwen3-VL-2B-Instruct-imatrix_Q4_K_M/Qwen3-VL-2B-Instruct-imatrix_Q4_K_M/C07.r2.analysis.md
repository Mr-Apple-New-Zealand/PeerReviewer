### **Root Cause**
The root cause of the incident was a **misconfiguration in the config deploy OPS-81**, which **rotated the JWT signing key in the Auth service** but **did not update the validation logic in the Transactions API**. As a result, the Transactions API continued to validate against the **old key**, causing **401 errors** ("IDX10503: Signature validation failed") for all users.

This is a **configuration drift** issue that occurred during a **config deployment**, where the **APIs were not updated** to reflect the new key.
