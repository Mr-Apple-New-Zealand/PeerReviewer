**Summary:**  
Customers are not receiving payment receipt emails due to a failure in the email sending process, which is caused by a misconfiguration in the notification service’s key storage and lack of XML encryption. The log shows that the service is storing data protection keys in a non-persistent directory (`/app/.aspnet/DataProtection-Keys`) and has no XML encryptor configured, leading to keys being stored in unencrypted form. This results in the SMTP server rejecting the email send attempt with status code 535 ("Authentication unsuccessful, basic authentication is disabled").
