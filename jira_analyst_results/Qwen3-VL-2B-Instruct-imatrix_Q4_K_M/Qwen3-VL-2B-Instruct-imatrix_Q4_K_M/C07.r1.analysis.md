**Incident Timeline: BANK-450 – P1: Transfers failing for all users**

---

### **Summary**
- **Incident**: All transfers failing due to "Signature validation failed" error (IDX10503) in the Transactions API.
- **Root Cause**: JWT signing key was rotated in a config deploy (OPS-81) without updating the validation key in the Transactions API.
- **Status**: Resolved (Fixed), **Resolved on**: 2026-09-11 10:42.
- **Impact**: All users experiencing transfer failures; transfer error rate > 20% initially, down to <1% after rollback.

### **Root Cause**

- **Primary Cause**: The JWT signing key was rotated in a config deploy (OPS-81) **without updating the validation key** in the Transactions API.
- **Impact**: The Transactions API still validates against the **old key**, resulting in **"Signature validation failed"** errors (IDX10503).
- **Trigger**: The deployment occurred at **09:30**, and the error rate spiked at **09:47**.
- **Resolution**: The issue was resolved by **rolling back the config deploy**, which restored the old key in the Transactions API.

> **Root Cause**: A **key rotation without key update** in the Transactions API caused signature validation failures.
