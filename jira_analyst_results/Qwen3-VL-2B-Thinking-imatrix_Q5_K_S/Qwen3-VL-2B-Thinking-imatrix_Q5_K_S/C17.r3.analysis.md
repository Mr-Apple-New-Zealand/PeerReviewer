# Analysis of BANK-495: Batch actions screen throws 'Cannot read properties of undefined' and goes blank

## Summary
The batch actions screen in the Bank UI (version 4.7.0) is experiencing a JavaScript runtime error where the `sort()` method is being called on an undefined array. This results in the screen going blank and requiring users to reload. The error occurs when users interact with the batch actions screen, particularly during data sorting operations.

## Current state
- **Status:** Open (Unresolved)  
- **Owner:** Unassigned  
- **Blocking:** The root cause is unclear, as the error is intermittent and occurs in Production environment. No specific conditions have been identified that consistently trigger this issue.

## Key details
- **Affected components:** Web UI, Auth (specifically the batch actions screen)  
- **Affected versions:** bank-ui 4.7.0  
- **Steps to reproduce:**  
  1. Navigate to the batch actions screen  
  2. Attempt to sort data using the sort function  
  3. The screen goes blank and requires a reload  
- **Critical issue:** The error occurs when data is being sorted on the Batch Actions screen in the Production environment  
- **Root cause evidence:** The error message "Cannot read properties of undefined (reading 'sort')" indicates the code was trying to call the `sort()` method on an undefined array  
- **Technical context:** This occurs during the processing of an AJAX request to `/payments/batch/actions`  
- **Error context:** The error is traced to the `ie.project` function in the main application entry point  
- **Sentry event details:** The error occurred during a transaction with ID `/settlements/run/8214`  

## Risks and gaps
