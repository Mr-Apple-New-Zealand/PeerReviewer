### Root Cause
The root cause of the incident was:
- **JWT Signing Key Rotation Mismatch**: The config deploy OPS-81 rotated the JWT signing key for the Auth service, but the Transactions API continued to validate tokens against the old key, resulting in 401 errors ("IDX10503: Signature validation failed").
