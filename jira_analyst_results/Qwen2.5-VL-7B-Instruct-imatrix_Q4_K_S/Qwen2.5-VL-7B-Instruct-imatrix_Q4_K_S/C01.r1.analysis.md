### Summary
A customer attempting a transfer from their cheque account to savings on mobile web experienced a "Request timed out (ERR_TXN_504)" error, leading them to retry the transaction. This resulted in the cheque account being debited twice and the savings account being credited once, instead of the expected single debit and credit.

### Current State
- **Status:** In Progress
- **Owner:** Priya Nair
- **Blocking Factors:** The current issue is being addressed by PR #218, which aims to wrap the debit and credit in a single transaction and add Idempotency-Key header support. The PR is awaiting code review.

### Key Details
- **Steps to Reproduce (Staging):**

  2. Add more than 30s of latency between the API and the database (using toxiproxy).
  3. When ERR_TXN_504 appears, tap Retry.
