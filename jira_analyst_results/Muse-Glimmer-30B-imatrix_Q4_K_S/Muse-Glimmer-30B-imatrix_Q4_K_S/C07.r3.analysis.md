**Incident: BANK-450 – Transfers failing for all users**
Status: Resolved / Fixed. Assignee: Sam Okafor. Linked cause: OPS-81.

### Summary
All users could not complete transfers. Monitoring showed TransferErrorRate >20% and the Transactions API was returning 401 “IDX10503: Signature validation failed”. The incident was traced to a config deploy OPS-81 at 09:30 that rotated the JWT signing key for Auth without updating the key used by the Transactions API for validation. Rollback of OPS-81 restored service.

### Root cause
As stated in BANK-450 10:50 comment: “the JWT signing key was rotated in config deploy OPS-81 without updating the key the Transactions API validates against. A post-incident review is booked for 2026-09-16.”
Auth service began issuing tokens signed with the new key after the 09:30 config deploy OPS-81, while the Transactions API continued validating against the old key, causing 401 “IDX10503: Signature validation failed”.
