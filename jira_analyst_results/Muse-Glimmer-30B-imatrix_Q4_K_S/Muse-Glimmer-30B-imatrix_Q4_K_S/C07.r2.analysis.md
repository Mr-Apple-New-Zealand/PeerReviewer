**Root cause**
Root cause stated in BANK-450 at 10:50: the JWT signing key was rotated in config deploy OPS-81 without updating the key the Transactions API validates against. Auth issued tokens signed with the new key while Transactions API continued to validate against the old key, causing 401 “IDX10503: Signature validation failed” and transfer failures.
