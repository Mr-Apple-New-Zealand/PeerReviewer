### Root cause
Per *BANK-450* comments and resolution:

The JWT signing key was rotated in config deploy *OPS-81* at 09:30 without updating the key the Transactions API validates against. Auth service began issuing tokens signed with the new key, while the Transactions API continued to validate against the old key, resulting in 401 “IDX10503: Signature validation failed” and transfer failures for all users.

Post-incident review booked for 2026-09-16.
