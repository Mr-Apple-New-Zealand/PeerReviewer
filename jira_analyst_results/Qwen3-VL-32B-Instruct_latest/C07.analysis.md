**Root Cause**  
The JWT signing key was rotated in config deploy OPS-81 without updating the key used by the Transactions API for signature validation. This caused the Transactions API to reject valid tokens signed with the new key, resulting in 401 errors (`IDX10503: Signature validation failed`) for all transfer requests.

This was a configuration drift issue between Auth and Transactions services, triggered by an incomplete deployment. The fix was a rollback of the config deploy (OPS-81).
