# BANK-471: Customers are not receiving payment receipt emails

## Summary
Customers stopped receiving payment receipt emails around 14:00 today, causing increased contact center call volume. The issue is caused by the application failing to authenticate with the SMTP server due to missing secure key storage configuration. The log shows repeated SMTP failures with code 5.7.139 ("Authentication unsuccessful, basic authentication is disabled") when attempting to send payment-receipt emails to customers.

## Current state
- Status: In Progress | Resolution: Unresolved | Priority: Highest
- Owner: Marcus Reid (reporter/assignee)
- Blocked by: Key storage configuration issues causing persistent SMTP authentication failures
- Restarting the pod at 18:02 did not resolve the problem, as evidenced by the log showing the issue persisted after restart (with multiple failed delivery attempts)

## Key details
- **Steps to reproduce**: 
  - Application attempts to send payment receipts via SMTP to customers
  - Authentication fails with "System.Net.Mail.SmtpException: The SMTP server requires a secure connection or the client was not authenticated. The server response was: 5.7.139 Authentication unsuccessful, basic authentication is disabled."
  - Error occurs immediately after pod restart (18:02:48) with multiple retry attempts

- **Affected components**: Notifications API (Bank.Notifications.API)
