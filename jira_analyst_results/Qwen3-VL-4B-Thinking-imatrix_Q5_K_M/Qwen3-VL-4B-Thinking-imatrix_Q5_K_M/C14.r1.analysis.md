# OPS-92 Analysis: Payments API Log Triage

## Summary
Users report "saving a secondary branch on a payment routing rule" fails without error code. The log shows the Payments API is failing when trying to access branch location data from masterfile-api with a 403 Forbidden error during secondary branch operations, preventing successful saves. This causes the UI to "spin and then say it failed" without clear error message.

## Current State
- Status: Open (created 2026-09-15 07:20, last updated 2026-09-15 08:05)
- Owner: Unassigned (no owner specified)
- Blocking progress: The core issue prevents users from saving secondary branches on payment routing rules, with no clear error message provided to them
- Priya Nair's comment notes platform needs to determine if this is the Payments API or database team's issue

## Key Details
- **Steps to reproduce**: Attempting to save a secondary branch on a payment routing rule results in UI spinning then "failed" state
- **Affected components**: Payments API (client) and masterfile-api (server)
- **Error pattern**: 
  - Dapr.Client.InvocationException: `403 (Forbidden)` when calling masterfile-api's branchlocation service
  - Occurs during specific operations:
    - `AddPaymentRoutingRuleSecondaryCommand` (e.g., `RuleSetId: 41001, SecondaryBranchID: 71`)
    - `BulkUpdateSecondaryBranchesCommand`
- **Critical error log**:
  ```
  [19:13:31 ERR] ERROR Handling transaction for AddPaymentRoutingRuleSecondaryCommand ({"RuleSetId": 41001, "SecondaryBranchID": 71})
  Dapr.Client.InvocationException: An exception occurred while invoking method: 'branchlocation/get?ID=71&includeDetails=False' on app-id: 'masterfile-api'
  ---> System.Net.Http.HttpRequestException: Response status code does not indicate success: 403 (Forbidden).
  ```
- **Missing information**: 
  - No timestamp of when exact failures occurred (logs cover 48-hour period)
  - No user-specific context or environment details (e.g., browser, user account)
  - No indication of whether this is a one-time issue or recurring pattern
