# BANK-360: Migrate transactional email from SMTP to the EmailHub API

## Summary
This ticket aims to migrate all transactional emails (password resets, statements, transfer receipts) from SMTP to the EmailHub API. After addressing attachment size limitations (initially failing due to 10MB limit on attachments), the team changed strategy to send statements as secure download links instead of attachments. The migration is now almost complete with the EmailHub client implemented and templates migrated, but the load testing remains blocked until performance testing environment availability.
