# BANK-360: Migrate transactional email from SMTP to the EmailHub API

## Summary
This story migrates all transactional emails (password resets, statements, transfer receipts) from SMTP relay to EmailHub API. The scope includes implementing EmailHub client in EmailService, migrating templates to EmailHub, handling bounce/complaint webhooks, and conducting load tests. Early testing revealed attachment size limitations with EmailHub (25MB statements exceed 10MB limit), leading to a decision to send statements as secure download links instead of attachments. The migration now includes a feature flag to enable EmailHub with SMTP as a fallback until 2026-12-31.
