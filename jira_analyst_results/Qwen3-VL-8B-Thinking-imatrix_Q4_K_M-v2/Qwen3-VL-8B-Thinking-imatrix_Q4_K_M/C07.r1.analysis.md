### Root Cause  
The config deploy OPS-81 rotated the JWT signing key for Auth at 09:30, but the Transactions API continued validating tokens with the *old* key, resulting in 401 errors ("IDX10503: Signature validation failed").  

*Note: "Time to detect" uses the first error observation (09:31) as the incident start time. "Time to recover" uses the error rate dropping below 1% (10:42) as the resolution milestone, as explicitly confirmed by Sam Okafor.*
