# OPS-92: Payments API: log dump for triage after user reports of failed saves

## Summary
Users report that saving a secondary branch on a payment routing rule "just spins and then says it failed" without error codes. The log shows multiple 403 Forbidden errors when the Payments API attempts to access branch location information from masterfile-api via Dapr. The specific issue occurs during AddPaymentRoutingRuleSecondaryCommand operations, particularly with Branch ID 71, and affects both saving secondary branches and bulk updating secondary branches.

    ---> System.Net.HttpRequestException: Response status code does not indicate success: 403 (Forbidden).
