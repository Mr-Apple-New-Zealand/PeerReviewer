## Key details

**Likely shared cause — 401 cascade affecting payments/settlements (candidate #1):**
- BANKUI-4A1, 4A2, 4A9, 4B3 are all unhandled `TypeError`s (`sort`, `rows`, `returnProperties`, `length` on undefined) across related routes (`/settlements/run/...`, `/payments/batch/actions/...`).
- Each breadcrumb summary shows the error immediately preceded by `401` responses from different backend endpoints.
- `firstSeen`/`lastSeen` cluster tightly (all last seen ~07:23 UTC on 2026‑09‑12; three start within the same second on 2026‑09‑05), which is consistent with a shared underlying trigger (e.g. a session/auth expiry) rather than four independent bugs. **This is an inference** based on timestamp clustering and shared 401 breadcrumbs, not a confirmed root cause.
- BANKUI-3C8 (`HttpErrorResponse 401`, 5,140 events, 44 users, `handled: true`) is the app's own console logging of every failed request — it's not a crash, but its volume corroborates how widespread the 401s are. It should be treated as supporting evidence for the cluster above, not a separate fix item.
- Combined, this cluster touches up to ~44 distinct users (exact overlap unknown — the export explicitly warns user counts can't be summed) in core settlement/payment workflows.

**Deployment-related — ChunkLoadError (candidate #2):**
- BANKUI-5D6 (`ChunkLoadError: Loading chunk 6728 failed`) first appeared 2026‑09‑10T21:11:36Z, minutes after release 4.7.0 deployed (2026‑09‑10T21:05:00Z). Breadcrumb: "a navigation immediately before; the requested bundle returns 404."
- Only 63 events but 58 distinct users — the highest user count of any issue in the export, and unusual in that events ≈ users (near 1:1), consistent with a classic post-deploy stale-asset issue (users with an old page open requesting a chunk hash that no longer exists).
- Note: the same chunk (`6728.b4f17ce620a8d539.js`) is referenced in the `lastFrame` of BANKUI-4A1 and 4A2, meaning this bundle covers the same allocation-reports/settlements code area as the 401 cluster — worth keeping in mind if the two are investigated together, though nothing in the data confirms they share a root cause.
