**Root Cause**
Config deploy OPS-81 rotated the JWT signing key used by the Auth service, but the Transactions API was not updated to validate tokens against the new key. Auth continued issuing tokens signed with the new key while Transactions API still validated against the old one, causing all transfer requests to fail signature validation (401, "IDX10503: Signature validation failed"). Rolling back OPS-81 restored matching keys and resolved the incident.
