**Root cause**
JWT signing key was rotated for the Auth service by config deploy OPS-81, but the Transactions API was not updated to validate against the new key. Transactions API therefore rejected tokens issued by Auth with 401 errors ("IDX10503: Signature validation failed"), causing all transfers to fail. Confirmed by Sam Okafor (BANK-450 is linked as "is caused by" OPS-81).

**Incident timeline (NZST)**
- 09:30 — OPS-81 config deploy rotates Auth service's JWT signing key
- ~09:31 — Transfer errors begin (per dashboard review, comment 09:52)
- 09:47 — Monitoring alert fires: TransferErrorRate > 20%
- 09:52 — Incident declared by Sam Okafor; error rate at 64%
- 10:05 — Support reports 40+ calls in 15 minutes (customer impact confirmed)
- 10:10 — Priya Nair raises possible DB cause (slow queries)
- 10:24 — Sam Okafor rules out DB; identifies 401 "IDX10503: Signature validation failed" and traces cause to OPS-81 key rotation mismatch
- 10:31 — Rollback of OPS-81 config deploy started
- 10:42 — Transfer error rate back under 1%
- 10:44 — Rollback confirmed complete
- 10:50 — Incident resolved; post-incident review scheduled for 2026-09-16
