## Time to Detect (TTD)

- **Error onset → alert firing:** 09:31 → 09:47 = **~16 minutes**

The onset time (09:31) is based on dashboard observation stated by Sam Okafor, not a hard log timestamp, so treat it as approximate.

## Time to Recover (TTR)

- **Error onset → error rate <1%:** 09:31 → 10:42 = **~71 minutes**
- **Incident declared → error rate <1%:** 09:52 → 10:42 = **~50 minutes**
- **Root cause identified → resolved:** 10:24 → 10:42/10:50 = **~18–26 minutes** (time to execute the rollback once cause was known)

## Root Cause

Config deploy **OPS-81** (09:30) rotated the JWT signing key used by the Auth service, but the Transactions API was not updated to validate against the new key. Auth issued tokens signed with the new key while Transactions API still validated against the old one, causing widespread 401 failures (`IDX10503: Signature validation failed`) and blocking all transfers. Fixed by rolling back the OPS-81 deploy.

**Note:** The database slow-query hypothesis raised by Priya Nair (10:10) was investigated and explicitly ruled out by Sam Okafor (10:24), who attributed it to normal time-of-day load, not the incident cause.
