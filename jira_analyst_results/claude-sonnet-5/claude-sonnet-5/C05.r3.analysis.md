## Answer: Yes — BANK-425 is a likely duplicate of BANK-440

**BANK-425 and BANK-440 describe the same defect:**
- Both report stale balance on the **web** dashboard/home screen after a transfer (BANK-440: Components=Transactions, BANK-425: Components=Web — inconsistent component tagging, but same symptom).
- Both are on **Affects version 3.1.4**.
- Both note that refreshing/reloading normal ways doesn't help; BANK-440 adds that logging out and back in does fix it, and confirms the API itself returns the correct balance — this is consistent with a client-side cache issue, not a backend bug.

**MOB-88 is not a duplicate** — it's a distinct bug: mobile push notifications (not the web dashboard) showing a stale balance, caused by using the `TransferRequested` event instead of `TransferCompleted`. Different platform, different root cause, already has an owner and a proposed fix.
