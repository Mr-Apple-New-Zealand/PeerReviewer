# BANK-412 Analysis

## Summary
When a transfer times out on mobile web and the user taps "Retry", the source account is debited twice while the destination account is only credited once. This occurs because the retry action is treated as a new transfer (no idempotency key) and the debit/credit operations are not in a single database transaction. Three customers have reported this issue with support calls on 5, 6, and 8 September.
