# BANK-412 Analysis

## Summary
When a transfer times out on mobile web and the user taps "Retry", the source account is debited twice while the destination account is only credited once. This occurs because the retry request lacks an idempotency key and the debit/credit operations are not in a single database transaction. Three customers have been impacted, with duplicate debits requiring manual reversal.
