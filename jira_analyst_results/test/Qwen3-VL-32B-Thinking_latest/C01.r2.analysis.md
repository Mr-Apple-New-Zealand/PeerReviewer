# BANK-412 Analysis

## Summary
When a transfer times out on mobile web and the user taps "Retry", the source account is debited twice while the destination account is credited only once. This occurs because the retry request is treated as a new transaction (no idempotency key) and the debit/credit operations are not in a single database transaction. Three customers have been affected, requiring manual reversal of duplicate debits.
