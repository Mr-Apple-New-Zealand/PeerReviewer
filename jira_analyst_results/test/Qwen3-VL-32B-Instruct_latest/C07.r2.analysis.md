→ **16 minutes**

**Time to Recover (TTR)**  
= Time from when incident was declared (09:52) to when service was restored (10:42)  
→ **50 minutes**

*(Note: If using time from first error to recovery, TTR is 71 minutes. But standard practice is to measure from incident declaration, which is when the team formally acknowledges and acts.)*

**Root Cause**  
The JWT signing key was rotated in config deploy **OPS-81** without updating the key used for signature validation in the **Transactions API**. This caused the API to reject valid tokens signed with the new key, resulting in 401 errors (`IDX10503: Signature validation failed`) for all transfer requests.

This was a configuration drift issue between Auth and Transactions services during a key rotation. The rollback of OPS-81 resolved the issue. A post-incident review is scheduled for 2026-09-16.
