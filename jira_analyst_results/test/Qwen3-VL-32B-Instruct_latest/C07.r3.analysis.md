- **09:31 NZST**: Transfer errors begin to appear in monitoring dashboards.

- **09:52 NZST**: Incident declared by Sam Okafor. Error rate at 64%.

- **10:31 NZST**: Sam Okafor initiates rollback of OPS-81 config deploy.
- **10:42 NZST**: Transfer error rate drops below 1% after rollback.

**Time to Detect (TTD)**  
= Time from first error occurrence to incident declaration  
= 09:52 - 09:31 = **21 minutes**

**Time to Recover (TTR)**  
= Time from incident declaration to recovery (error rate <1%)  
= 10:42 - 09:52 = **50 minutes**

---

**Root Cause**  
The JWT signing key was rotated in config deploy **OPS-81** without updating the key used by the **Transactions API** for token validation. This caused all incoming requests to fail with `IDX10503: Signature validation failed` (401 Unauthorized), as the Transactions API could not validate tokens signed with the new key. The issue was resolved by rolling back the config deploy.
