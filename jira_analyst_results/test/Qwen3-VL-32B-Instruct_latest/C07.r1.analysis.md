- **10:31 NZST**: Rollback of config deploy OPS-81 initiated.

- **TTR**: **50 minutes**

---

### **Root Cause**

> **The JWT signing key was rotated in config deploy OPS-81 without updating the key used by the Transactions API for signature validation.**

This caused the Transactions API to reject valid tokens from the Auth service, resulting in 401 "Signature validation failed" errors (IDX10503) for all transfer requests.

- **Linked Issue**: OPS-81 (config deploy that caused the issue) is explicitly linked as "is caused by".
- **Post-Incident Review**: Scheduled for 2026-09-16.
- **Impact**: All users affected; high support volume.
- **Resolution**: Rollback of OPS-81 config deploy.
