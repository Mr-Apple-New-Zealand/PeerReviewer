### Time to Detect

The time to detect is the duration from when errors first appeared in the dashboards until the monitoring alert fired. 

- **Time to Detect**: 09:47 - 09:31 = 16 minutes.

### Time to Recover

The time to recover is the duration from when the incident was declared until the error rate returned to normal levels.

- **Time to Recover**: 10:42 - 09:52 = 50 minutes.

### Root Cause

The root cause of the incident was that the JWT signing key was rotated in the config deploy OPS-81 without updating the key the Transactions API uses for validation. This resulted in the Auth service issuing tokens signed with the new key, while the Transactions API still validated against the old key, causing transfer failures.
