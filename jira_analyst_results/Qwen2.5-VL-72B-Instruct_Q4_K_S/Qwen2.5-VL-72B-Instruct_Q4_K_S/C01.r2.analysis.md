### Summary
The bug causes a double debit when customers retry a timed-out transfer between their own accounts on mobile web. This issue has affected three customers and is due to the lack of idempotency in the retry mechanism and improper transaction handling.

### Current state

- **Owner:** Priya Nair
- **Blocking progress:** Waiting for code review of PR #218, which addresses the root causes identified.

### Key details
#### Steps to reproduce:
- Log in on mobile web.
- Introduce more than 30 seconds of latency between the API and database.
- When a timeout error appears, tap Retry.

#### Affected components or versions:
- Components: Transactions
- Affects versions: 3.1.4
