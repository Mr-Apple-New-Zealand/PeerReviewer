### Root Cause  
The JWT signing key rotation in config deploy **OPS-81** (at 09:30 NZST) was not synchronized with the Transactions API. Auth service began issuing tokens with the new key, but the Transactions API continued validating against the old key, causing `IDX10503: Signature validation failed` errors (401s).
