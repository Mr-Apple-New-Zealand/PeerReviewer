# OPS-92: Payments API: log dump for triage after user reports of failed saves

## Summary
Two users reported that saving a secondary branch on a payment routing rule "just spins and then says it failed" with no error code provided. The log shows multiple 403 Forbidden errors when the Payments API attempts to call the masterfile-api service for branch location information during secondary branch operations. The log indicates this is a recurring issue affecting multiple rule sets (41001, 41002, etc.), with the same error pattern occurring repeatedly.
