# OPS-92: Payments API: log dump for triage after user reports of failed saves

## Summary
Users cannot save secondary branches on payment routing rules due to 403 Forbidden errors when accessing branch information from masterfile-api. The log shows multiple instances of this error during AddPaymentRoutingRuleSecondaryCommand operations, matching the reported behavior of "just spins and then says it failed" with no error code. The issue appears to be related to authentication/authorization between payments-api and masterfile-api services.

## Current state
- **Status**: Open
- **Owner**: Unassigned
- **Blocking progress**: Log analysis is complete but requires determination of root cause. Priya Nair's comment indicates the team needs to determine if this is a payments-api or database team issue before proceeding.

  - System hangs and returns failure without error code
